RPGShopSystem
This project was created to strengthen my understanding of object-oriented programming in C#. The application simulates a simple RPG shop where players can purchase items, manage inventory, and spend in-game gold.

Concepts Practiced
Classes and Objects
Constructors
Properties
Methods
Encapsulation
Object Interaction
Collection Management
State Changes
Validation
Console Applications
System Design
Player ↓ Inventory ↓ ShopItems

Shop ↓ ShopItems

The Player class manages gold and purchasing logic. The Inventory class stores purchased items, while the Shop manages available items for purchase.

Features
Create Players
Create Shop Items
Build Shop Inventories
Purchase Items
Spend Gold
Manage Player Inventory
Display Purchased Items
